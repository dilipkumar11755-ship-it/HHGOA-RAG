System behavior
GUARDRAILS AS EVIDENCE
Input Filter
Accepted / Rejected
Off-topic and unsafe patterns (weapons, illegal activity) are blocked before retrieval even runs. Try the "watch it refuse" chip above.
Confidence Gate
Score-routed
Score ≥ 0.92 → instant extraction. 0.40–0.92 → LLM with context. Below 0.40 → honest refusal. No guessing.
Grounding Check
Verified
LLM answers are checked for keyword overlap with source context. Answers not grounded in retrieved passages are flagged.
Junk Filter
Active
Passages containing ad copy, cookie notices, and web scrape noise are filtered out before answer extraction.
